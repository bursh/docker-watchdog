Docker Watchdog

Centralized HTTP monitoring and automatic recovery for Docker Compose on Linux.

OverviewInstallationManualReleasesGitHub

One service. Multiple projects.

Discover opt-in Compose services through Docker labels. Resolve their published HTTP ports automatically. After three failed checks (by default), recover the affected Compose project, then wait through cooldown and verify availability.

Quick start

  1. Install the DEB or follow the platform installation guide.
  2. Add the labels below to the HTTP service publishing one port.
  3. Run docker compose up -d, then sudo docker-watchdog --status.
labels:
  watchdog.enabled: "true"
  watchdog.path: "/health"
  watchdog.mode: "restart"

Use / if a dedicated health endpoint is unavailable. A redirect counts as reachable, so a meaningful application endpoint is preferable.

Recovery modes

Mode Operation
restart Restart existing Compose containers
force-recreate Recreate containers using up -d --force-recreate
down-up Remove and recreate containers and project networks

Optional escalation, persistent restart limits, maintenance pause/resume, logs, webhooks and loopback Prometheus metrics are supported. max_restarts = 0 permits unlimited attempts; cooldown still applies.

Operational safety

Run only on trusted Linux hosts. Docker access is root-equivalent. Pause projects before maintenance and use named volumes and fixed published ports. Test on isolated infrastructure before enabling recovery. See the full manual and security policy.

Supported environments

Debian/Ubuntu are the primary target; other compatible systemd Linux distributions have a manual installation path but are not integration-tested. No native Windows or macOS support. See installation.

Project status

Source snapshots v1.0.0 through v1.2.2 are preserved as Git tags. Release assets and this site become available after the repository owner publishes them. CI includes unit tests and a Docker integration script; deployment and integration status should be checked in GitHub Actions.
