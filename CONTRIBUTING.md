# Contributing

Open an issue for substantial changes. Fork the repository and create a focused branch. Keep changes small, document behavior and add regression tests. Run `python3 -m unittest -v`, `node --test tests/configurator.test.js`, `bash build-deb.sh` and `bash build-rpm.sh` (with RPM tools installed). Run `bash tests/integration.sh` only on a disposable Docker host. Do not paste production logs, credentials, hostnames or private infrastructure. Include sanitized reproduction steps and version information. Prefer Conventional Commits; changes should preserve configuration/state compatibility or explicitly document migration. Update the changelog and manual for user-facing changes. Contributions are under the repository's Apache-2.0 license.
